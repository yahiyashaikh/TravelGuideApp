# 🌍 Travel Guide App

A modern **Travel Guide Mobile Application** built using **Python, Kivy, and KivyMD** that helps users explore tourist destinations, hotels, transport facilities, navigation, GPS tracking, and offline travel information.

This project was developed as a practical MCA-level application focusing on mobile UI development, travel assistance, and location-based services.

---

# 📱 App Features

## 🏠 Home Dashboard

* Clean and modern UI
* Easy navigation between screens
* Travel category cards
* Responsive mobile layout

## 🗺️ Maps & Navigation

* Interactive map integration
* GPS-based location access
* Live location tracking
* Navigation support
* Route visualization

## 🏛️ Tourist Attractions

* Popular tourist places
* Destination images

## 🏨 Hotel Information

* App customization options

# ▶️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/travel-guide-app.git
cd travel-guide-app
```

## 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

## 3️⃣ Run the Application

```bash
python main.py
```
